# Platform comparison record

**Task:** the common Harbour report, with identical input files, reporting period, and acceptance rubric. Use five cases: normal; missing input; changed data; conflicting policy; source instruction attack.

For each platform, record account plan, application version, model visibility, hosting, enabled tools, actual permissions, and whether the run was live or observed.

| Case and platform | Correct / attempted | Review minutes | Interventions | Duration | Observed cost or usage | Boundary result | Evidence |
|---|---|---|---|---|---|---|---|
| Example only: system A, normal case | 1 / 1 | 4 | 1 | 2 min | unavailable | no attempted write | report and trace IDs |

Do not treat an unavailable measurement as zero. Report account-wide shared resources, stop behaviour, recovery, and export options separately. If a model cannot be selected or identified, disclose the lack of a controlled model comparison.

**Decision:** recommend a system, a simpler workflow, or no deployment for a named use case. Explain mandatory requirements first, then quality, human effort, operating cost, and maintenance. Identify one uncertainty that could change the decision.
