# Course content

Sixteen complete weekly chapters for the October 2026 practical course. Each includes concepts, a worked example, engineering and owner studio routes, and required evidence. Start with [setup](../SETUP.md), then work in order with the [Harbour Services case](case-study/README.md).

| Week | Chapter | Purpose |
|---|---|---|
| 1 | [AI Foundations and Useful Work](weeks/01.md) | Choose a worthwhile task and measure the process before changing it. |
| 2 | [Prompting, Context, and Research](weeks/02.md) | Turn vague requests into verifiable briefs and check the evidence behind answers. |
| 3 | [Data, Documents, and Media](weeks/03.md) | Check calculations and preserve source evidence when working with files and recordings. |
| 4 | [AI-Assisted Engineering](weeks/04.md) | Deliver a small software change with requirements, review, tests, and rollback. |
| 5 | [Model APIs and Structured Outputs](weeks/05.md) | Build validated interfaces and handle incomplete, refused, and incorrect responses. |
| 6 | [Private Knowledge and Retrieval](weeks/06.md) | Answer from the right version of authorised documents and abstain without evidence. |
| 7 | [Business Workflow Automation](weeks/07.md) | Use durable states, approvals, and idempotent effects to make workflows recoverable. |
| 8 | [Agents, Tools, MCP, and Memory](weeks/08.md) | Give agents useful tools with enforced boundaries and observable execution. |
| 9 | [OpenClaw in Practice](weeks/09.md) | Operate a restricted assistant through a test messaging channel. |
| 10 | [Hermes Agent in Practice](weeks/10.md) | Teach a reusable procedure and verify what persists across sessions. |
| 11 | [Grok Bot and Platform Comparison](weeks/11.md) | Delegate a cloud task and compare complete systems on identical cases. |
| 12 | [Evaluation, Security, and Governance](weeks/12.md) | Use independent cases and failure evidence to make a release decision. |
| 13 | [Deployment, Economics, and Adoption](weeks/13.md) | Prepare a monitored pilot with ownership, a recovery path, and an honest business case. |
| 14 | [Capstone: Implement](weeks/14.md) | Complete one narrow end-to-end system and freeze acceptance criteria. |
| 15 | [Capstone: Pilot and Improve](weeks/15.md) | Observe real or clearly simulated use, fix failures, and compare with the baseline. |
| 16 | [Capstone: Demonstrate and Hand Over](weeks/16.md) | Demonstrate success, failure, blocked action, and recovery, then defend the adoption decision. |

Use the [lab guide](labs/README.md), [assessment guide](../ASSESSMENTS.md), [capstone](../CAPSTONE.md), and [primary research register](research.md). The site presents these chapters as 48 lessons with 128 knowledge questions.
