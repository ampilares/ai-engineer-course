# Resources

The core chapters are self-contained teaching material with linked primary references. Begin with the [course index](course/README.md), [case pack](course/case-study/README.md), and [lab guide](course/labs/README.md). The [research register](course/research.md) records what the official sources support and what still needs a live test.

## By purpose

- **Choose a task and architecture:** [Anthropic: Building effective agents](https://www.anthropic.com/engineering/building-effective-agents). Read for the distinction between fixed workflows and agent-selected actions.
- **Work with a coding assistant:** [Codex learning resources](https://developers.openai.com/learn/codex), [Claude Code overview](https://code.claude.com/docs/en/overview), and [Cursor Agent overview](https://cursor.com/docs/agent/overview). Use the chosen product's current setup documentation.
- **Validate model responses:** [OpenAI structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs). Read alongside the sample's refusal, incomplete-response, and business-validation paths.
- **Understand retrieval:** [Retrieval-Augmented Generation paper](https://arxiv.org/abs/2005.11401). Read for the research origin; production permissions and source lifecycle remain application responsibilities.
- **Connect tools:** [MCP introduction](https://modelcontextprotocol.io/docs/getting-started/intro) and [official Python SDK](https://github.com/modelcontextprotocol/python-sdk).
- **Build reviewed automation:** [n8n human review](https://docs.n8n.io/advanced-ai/human-in-the-loop-tools/) and [SQLite transactions](https://sqlite.org/lang_transaction.html).
- **Operate OpenClaw:** [Getting started](https://docs.openclaw.ai/start/getting-started), [security audit](https://docs.openclaw.ai/cli/security), and [sandboxing](https://docs.openclaw.ai/gateway/sandboxing).
- **Use Hermes Agent:** [Quickstart](https://hermes-agent.nousresearch.com/docs/getting-started/quickstart), [memory](https://hermes-agent.nousresearch.com/docs/user-guide/features/memory), and [skills](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills).
- **Use Cursor's Grok Bot:** [Product documentation](https://cursor.com/docs/grok-bot), [security](https://cursor.com/docs/grok-bot/security), [routines](https://cursor.com/help/grok-bot/routines), and [model routing](https://cursor.com/help/grok-bot/models).
- **Evaluate and operate:** [OpenAI evaluation guidance](https://developers.openai.com/api/docs/guides/evaluation-best-practices), [OWASP prompt injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/), and [Google SRE objectives](https://sre.google/sre-book/service-level-objectives/).

For deeper work, use [the extension assignments](course/extensions.md). External resources retain their owners' licences and may describe features requiring paid access.
