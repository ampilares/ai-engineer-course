Memory stores selected information across sessions. Skills describe procedures and may include supporting files. The live conversation contains temporary task context. The [memory documentation](https://hermes-agent.nousresearch.com/docs/user-guide/features/memory) explains that persistence requires an actual write; an assistant saying it remembered something is not evidence of a saved entry. Confirm the stored artifact or recorded write, then test in a fresh session.
