This week produces an analysis that another person can reproduce. Keep the raw source, transformation rules, calculated results, and interpretation distinguishable. The same discipline applies whether the assistant reads a CSV, screenshot, PDF, or recording.

Read [the Harbour data contract](/course-materials/course/case-study/README.md) before touching the CSV. A transaction ID identifies a business event. One duplicate row does not represent additional income. A missing amount is unknown; replacing it with zero conceals a data problem. USD and AUD cannot be summed as though they were the same unit.

Use four stages: preserve, validate, transform, and reconcile. Preserve the original file. Validate columns, date formats, identifiers, currency, and amount representation. Transform only records that meet the stated rules. Reconcile counts so that every input row has an explanation.
