Real data never arrives one value at a time: it arrives as *collections*: a list of orders, a dictionary of fields, a list of dictionaries from an API. Master these two shapes and the loops that process them, and you will recognize a large share of practical data work.

## Lists: ordered sequences

```python
amounts = [4180, 990, 12500, 340]
amounts[0]          # 4180: positions count from ZERO
amounts[-1]         # 340: negatives count from the end
len(amounts)        # 4
amounts.append(75)  # add to the end
```

## Dictionaries: labeled records

A **dict** maps keys to values: the natural shape of a record, and exactly what APIs and models exchange (as JSON, next lesson):

```python
invoice = {"vendor": "Nordwind", "total": 4180, "paid": False}
invoice["vendor"]            # "Nordwind"
invoice["due"] = "2026-08-01"  # add a field
invoice.get("iban")          # None: .get() is the safe lookup
invoice["iban"]              # KeyError!: [] on a missing key crashes
```

That last line matters: `[]` on a missing key raises an exception; `.get()` returns `None` (or a default). Choosing between them is choosing what should happen when data is incomplete: a real design decision you'll make constantly.

## Loops: doing something with each item

```python
invoices = [
    {"vendor": "Nordwind", "total": 4180},
    {"vendor": "Baltic Freight", "total": 990},
    {"vendor": "CargoOne", "total": 12500},
]

big = []
for inv in invoices:              # inv is each dict in turn
    if inv["total"] > 1000:
        big.append(inv["vendor"])
# big == ["Nordwind", "CargoOne"]
```

Python has a beloved shorthand for exactly this filter-and-transform pattern, the **comprehension**:

```python
big = [inv["vendor"] for inv in invoices if inv["total"] > 1000]
total_value = sum(inv["total"] for inv in invoices)
```

Read it aloud: *"the vendor, for each invoice, if its total exceeds 1000."* Once it clicks, you'll see this pattern everywhere in AI code: filtering documents, transforming records, building prompt lists.

## The shape you'll see forever: list of dicts

Look again at `invoices` above: a **list of dictionaries**. Every API response, every dataset row collection, every batch of model outputs takes this shape. The fluency drill is always the same three moves (*loop over the list, reach into each dict, filter or transform*) and you just did all three.
