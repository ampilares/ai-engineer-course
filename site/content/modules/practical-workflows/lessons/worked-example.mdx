### Worked interruption

The provider accepts action A17. The worker crashes before marking A17 completed. On restart, the local record says approved, but the external effect may already exist. Retrying with a new action ID creates a duplicate. Retrying A17 with an identical payload against a provider that enforces idempotency returns the existing effect. Retrying A17 with changed content must be rejected, not silently treated as the approved action.
