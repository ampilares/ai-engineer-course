This week collects evidence from bounded use. Run with a small authorised group, or label the work as a simulation. The objective is to learn whether the system improves the agreed process and to fix the most consequential observed failure.

Before the first case, confirm the operating mode, participants, reporting window, budget, review duty, and stop conditions. Keep a record of every attempted case, including cancellations and incomplete runs. Save original outputs before corrections so you can distinguish model performance from final staff-assisted performance.

For each case record input reference, configuration version, start/end, active staff minutes, waiting time, review outcome, correction type, final success, and cost. A run that finishes quickly but spends a day waiting for an unassigned reviewer has poor end-to-end service. Separate those two timings.
