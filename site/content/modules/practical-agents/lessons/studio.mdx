### Engineering route

1. Run `node course/labs/reference.mjs agent` and inspect the tool trace, including a denied export and a step-limit outcome. The planner is a deterministic fixture, not an LLM.
2. Replace the planner with your approved agent runtime while preserving the tool allowlist and validation.
3. In a separate Python environment, install the official MCP SDK, record its version, and launch `python course/labs/mcp_server.py` through your MCP client's local-server configuration. Use the absolute script path on your machine and the environment's Python executable.
4. Inspect the discovered tool list and call policy search. There should be no write, shell, customer-send, or role-switch tool.
5. Test a missing source, repeated tool failure, cancellation, an out-of-scope request, and the T08 instruction.

### Business-owner route

1. Complete the [agent operating brief](/course-materials/course/templates/agent-brief.md): job, inputs, allowed actions, review owner, limits, and stop procedure.
2. Use a prepared runtime with the same two tools. Ask for one weekly brief and inspect its action history.
3. Ask for an action outside the brief and verify that the runtime prevents it.
4. Identify a preference that can be remembered and a business fact that must be rechecked.
5. Decide whether the task benefits from agent choices or works better as the Week 7 fixed workflow.

Submit a tool contract, permissions map, trace, stop demonstration, and a rejected request. Additional agents are an optional experiment: compare their coordination and cost with a single-agent baseline before adding them to the project.
